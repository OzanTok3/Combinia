# Combinia 👗✨

Combinia, kullanıcıların kıyafet kombinlerini paylaşabileceği, beğenip yorum yapabileceği ve takip ettikleri kişilerin kombinlerini görebileceği bir mobil moda uygulamasıdır.

## 🚀 Özellikler
- 👥 Kullanıcı profili & takip sistemi
- 🧠 AI destekli kombin önerileri (planlanıyor)
- ❤️ Beğeni, yorum, favori listeleri
- 🏷️ Etiket sistemi
- 🔔 Bildirimler
- 💰 Reklam & premium gelir modeli

## 🛠️ Teknolojiler
- Kotlin + Jetpack Compose
- Firebase (Auth, Firestore, Storage, Messaging)
- Hilt, Navigation, Room (planlı)
- Git Flow (main/develop/feature)

## 📦 Mimari
- MVVM + Clean Architecture
- Modular yapı (data, domain, app)
